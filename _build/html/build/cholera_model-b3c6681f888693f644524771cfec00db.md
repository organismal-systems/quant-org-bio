# ️💡️  A discrete-time model of cholera immune period
This page explains key mathematical elements of [Koelle *et al*. (2005)](https://doi.org/10.1038/nature03820) cholera model.
This model has the structure if an [SIR](wiki:Compartmental_models(epidemiology)).
It assumes fluctuations in total population, $N$, are negligible, so that 
$$
R = N - S - I
$$
such that $R$ is an implicit variable.
