# Appendix

This Appendix contains guidelines, instructions and utilities helpful to users of this ebook. 
Sections currently implemented are;
- A list of [direct links to Binder implementations of Worksheets](./BinderList.md), aggregating access to all the modeling tools in one place 
- A [search tool](../../subrepos/overview/qob-notebooks/OSYMindex.ipynb), implemented as a Jupyter notebook, to locate ebook pages tagged by page type, key mechanism or organizational level

- [Instructions](../overview/localintro.md) for running Worksheets or building a copy of the ebook on your own computer
