💡️ Mathematical analysis of the KISS model

School of Oceanography, University of Washington

The KISS[1] model is expressed as a Partial Differential Equation (PDE) for the changes of a population with density p∗(t∗,x∗)p^*(t^*,x^*)p∗(t∗,x∗),

  • p∗p^*p∗ has units of individualslength\frac{individuals}{length}lengthindividuals​

  • α\alphaα has units of 1time\frac{1}{time}time1​

The KISS model assumes that a population is initially present in a 1-dimensional habitat of size LLL. The key question addressed by the KISS model is,

  • How large does habitat size LLL have to be for the population to persist?

This page develops two aspects of the KISS model. The first is non-dimensionalizing the KISS mode. This analysis will show that all KISS models are scale models of each other. That is, a KISS model with any choices of α\alphaα and DDD are rescaled versions of the “non-dimensional” KISS model with α=D=1\alpha = D = 1α=D=1. The second is an exact analytical solution for the KISS model.

Solution of the non-dimensional KISS model¶

To obtain an exact analytical solution for Equation (8), we can use an approach called Separation of Variables. This technique boils down to trying whether an equation involving two independent variables (in this case, ttt and xxx) can be solved as a product of a function of ttt alone with a function of xxx alone. This succeeds for only some types of PDEs; the KISS model is one of them.

To obtain a separable solution, we assume a solution of the form:

p=s(x)eσtp = s(x) e^{\sigma t}p=s(x)eσt
